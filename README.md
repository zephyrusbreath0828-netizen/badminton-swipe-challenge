# 🏸 Badminton Swipe Challenge

スマートフォン向けの、スワイプ操作で遊ぶ本格バドミントンゲーム。
ボタン連打ではなく、**画面上のスワイプの「長さ・方向・速度」**がそのままショットの種類・コース・威力に変換されます。

- バージョン: **v1.0.0**
- 技術: HTML / CSS / JavaScript（フレームワーク・ビルド不要）
- 対応: モバイルファースト（縦画面最適化） / PWA / オフライン起動
- 公開: GitHub Pages・Vercel にそのままデプロイ可能

## 特徴

| 項目 | 内容 |
| --- | --- |
| スワイプ判定 | 開始位置・終了位置・方向・長さ・速度を取得し、4種のショットへ変換 |
| 打点システム | シャトルの高さと位置で「打てる／打てない」「スマッシュ可否」を判定 |
| 利き手システム | 右利き／左利きでフォア・バックが反転。コース解釈も変化 |
| 完全自動移動 | 落下予測地点へ自動でフットワーク。プレイヤーはスイングに集中 |
| 疑似3D描画 | Canvas 2D による透視投影。アニメ調キャラクター＋パーティクル演出 |
| サウンド | WebAudio による完全合成（音声ファイル不要） |
| スコアアタック | 返球10点／スマッシュ30点。100点ごとにレベルアップしAIが強化 |
| PWA | manifest + Service Worker でホーム画面追加・オフライン起動に対応 |

## 操作方法

### 移動

**v1.0 は完全自動**です。プレイヤーはシャトルの落下予測地点へ自動的に移動します。
地面に表示される黄色いリングが予測着地点です。

### スイング

画面のどこでもスワイプできます。指を離した瞬間にショットが確定します。

```
         ↑ 短い      → ドロップ（ネット際へ落とす）
         ↑ 長い      → クリア（高く奥まで）
      ← →  横       → ドライブ（低く速い）
         ↓          → スマッシュ（打点が肩より高いとき）
```

- **スワイプ速度**が初速に比例します（遅い／普通／速いで球速が変化）
- **スワイプ角度**がコースになります（左＝クロス、上＝ストレート、右＝逆クロス）
- 打点が低い状態で下方向にスワイプすると**ミスショット**（ネット）になります

### サービス

サーブもスワイプで行います。シャトルを保持した状態で上方向へスワイプしてください。

| 操作 | サービス |
| --- | --- |
| 短い上スワイプ | ショートサービス |
| 長い上スワイプ | ロングサービス |
| 速い上スワイプ（フリック） | フリックサービス |

## ショット一覧

| ショット | 条件 | 軌道 | 球速 | 得点 |
| --- | --- | --- | --- | --- |
| **ドロップ** | 短い上スワイプ（132px未満） | 山なり・ネット際 | 遅い | 10点 |
| **クリア** | 長い上スワイプ（132px以上） | 高くて深い | 中 | 10点 |
| **ドライブ** | 横方向スワイプ | 低くフラット | 速い | 10点 |
| **スマッシュ** | 下スワイプ ＋ 打点1.32m以上 | 急降下 | 最速 | **30点** |

> スマッシュは「返球10点 + スマッシュボーナス20点」で合計30点です。

### 打点システム

ショット成立には**打点**の判定があります。

- シャトルがラケットの届く範囲（前後 約2.6m / 左右 約2.5m / 高さ 3.95m以下）にあること
- 範囲外でのスワイプは**空振り**（0.34秒の硬直）
- 打点の高さで威力と精度が変化（`PERFECT` 帯域では威力+10%）
- 打点が低すぎる状態での下スワイプは**ミスショット**（ネット）

プレイヤーの足元に黄色いリングが表示されている間が「打てる」タイミングです。

### 利き手システム

ゲーム開始前（ホーム画面 / 設定画面）に選択できます。

| 利き手 | フォア側 | バック側 |
| --- | --- | --- |
| 右利き | 身体の右側 | 身体の左側 |
| 左利き | 身体の左側 | 身体の右側 |

- **フォアハンド**: 威力 100% / 精度 100%
- **バックハンド**: 威力 84% / 精度 68%（コースがばらつく）
- 左利きはコース解釈が左右反転するため、**同じスワイプでも行き先が変わります**

## ゲームシステム

### スコア

| イベント | 得点 |
| --- | --- |
| 返球成功 | 10点 |
| スマッシュ成功 | 30点（10 + ボーナス20） |
| AIが返せない（ウィナー） | 15点 |

### レベルアップ

**100点ごとにレベルアップ**します。レベルに応じて以下が段階的に上昇します。

- AIの移動速度・反応速度・配球精度
- シャトルの飛行速度（最大 1.4倍）
- AIのスマッシュ頻度

### ラリー終了条件

プレイヤーが返せなかった場合、またはショットがアウト／ネットになった時点でラリー終了 → リザルト画面へ。
（AIがミスした場合はボーナス得点を得て、サーブからラリーを再開します）

### AI難易度

| 難易度 | 反応 | 移動速度 | ミス率 | スマッシュ頻度 |
| --- | --- | --- | --- | --- |
| 初級 | 0.42s | 5.4 m/s | 24% | 6% |
| 中級 | 0.28s | 6.7 m/s | 13% | 18% |
| 上級 | 0.18s | 8.1 m/s | 5% | 32% |

### エフェクト

| ショット | 演出 |
| --- | --- |
| ドロップ | 淡い軌跡・小さな光 |
| ドライブ | スピードライン |
| スマッシュ | 発光・衝撃波リング・画面シェイク・専用効果音 |
| レベルアップ | バナー＋上昇音 |

## PWA / オフライン対応

- `manifest.webmanifest` … アプリ名・アイコン・縦画面固定・テーマカラー
- `sw.js` … アプリシェルをプリキャッシュ。ナビゲーションはネットワーク優先、資産はキャッシュ優先
- ホーム画面に追加するとスタンドアロン起動（ブラウザUIなし）

> Service Worker は `https://` または `localhost` でのみ有効です。
> アイコンは `assets/` に 192 / 512 / maskable / apple-touch を同梱しています。

## 設計メモ（拡張方針）

v1.1 以降の機能追加を想定し、**「DOMに触る層」と「触らない層」を分離**しています。

- `js/core/*` … DOM を一切参照しない純粋ロジック。Node でそのままテスト可能
- `js/game.js` … 状態機械のみ。UIへは `game.emit('score' | 'callout' | 'state' …)` で通知
- `js/ui/*` … イベントを受け取って DOM を更新するだけ
- `js/render/*` … `camera.project(x, y, z)` を通してのみ座標を扱う

### 主な拡張ポイント

| 追加したい機能 | 触る場所 |
| --- | --- |
| 手動移動モード（v1.1） | `core/player.js` に仮想スティック入力を追加、 `game.updateRally` の自動目標を分岐 |
| キャラクター選択（v1.1） | `render/character.js` の `PALETTES` を差し替え可能に |
| 能力育成・ラケット収集（v1.2） | `config.js` のショット性能をプレイヤーステータス経由で上書き |
| トーナメント（v1.3） | `game.js` の状態機械に `tournament` フェーズを追加 |
| ダブルス（v2.0） | `core/player.js` を複数インスタンス化し、ヒット判定を拡張 |
| オンライン対戦（v2.0） | `game.js` の入力（スワイプ解析結果）と状態をシリアライズして送受信 |

## デプロイ

### GitHub Pages

```bash
git init
git add .
git commit -m "feat: Badminton Swipe Challenge v1.0.0"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

リポジトリの **Settings → Pages** で `Deploy from a branch` → `main` / `/ (root)` を選択。
`.nojekyll` を同梱しているため、そのまま配信されます。

### Vercel

```bash
npm i -g vercel
vercel        # プレビュー
vercel --prod # 本番
```

フレームワークプリセットは **Other**、ビルドコマンドは空、出力ディレクトリも空のままでOK（完全な静的サイト）。
`vercel.json` で `sw.js` のキャッシュ無効化とマニフェストの MIME を設定済みです。

## テスト

DOM を使わないヘッドレス検証を同梱しています（Canvas をスタブして実際にゲームループを回します）。

```bash
npm test
# または
node tools/smoke-test.mjs
```

検証内容:

- スワイプ解析（長さ・方向・速度）
- ショット判定（ドロップ/クリア/ドライブ/スマッシュ/ミスショット/利き手反転）
- サーブ判定
- デモ・プレイ中のゲームループが例外なく進行すること
- 得点・ラリー・レベルアップ・リザルト到達
- 難易度・利き手の組み合わせ

## バランス調整

数値はすべて `js/config.js` に集約しています。主な調整ポイント:

| キー | 内容 |
| --- | --- |
| `shots.*.flight` | 滞空時間（小さいほど速い） |
| `shots.*.depth` | 落下地点の範囲（奥行き） |
| `input.dropMaxLength` | ドロップ／クリアの境界（px） |
| `input.smashMinContactY` | スマッシュ可能な打点の高さ |
| `player.reachX/Z` | 打てる範囲 |
| `difficulty.*` | AIの反応・速度・ミス率 |
| `scoring.*` | 得点とレベルアップ間隔 |

`camera.*` を変えるとコートの見え方（画角）が変わります。

## 既知の制約

- コートは正式寸法を簡略化した疑似3D表示です（横方向は画面に収めるため圧縮しています）
- BGM は未実装（効果音のみ）。`core/audio.js` に追加口を用意しています
- ランキングは端末内 `localStorage` 保存（サーバー同期なし）
- iOS Safari では初回タップまで無音です（WebAudio の自動再生制限。仕様どおりの挙動）
